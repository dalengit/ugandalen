# Ugandalen Content Roadmap

The site should grow as a deliberately unreliable community archive documenting Ugandalen, an unidentified digital figure whose patterned outfit has become an object of obsession.

## First batch

- [x] Recent Sightings — timestamped reports from public lobbies.
- [x] Witness Testimonies — increasingly unreliable encounter reports.
- [x] Outfit Analysis — a scientific breakdown of the pattern's alleged powers.
- [x] Ugandalen Field Guide — instructions for surviving a manifestation.
- [x] Frequently Avoided Questions — answers that reveal almost nothing.

## Future transmissions

- [ ] Known Abilities — immaculate presence, pattern manipulation and silent judgment.
- [ ] Imitation Gallery — failed recreations of the sacred outfit.
- [ ] Ugandalen Timeline — contradictory events dating from before the internet.
- [ ] Conspiracy Board — connect sightings, usernames and unexplained disconnects.
- [ ] Official Merchandise — fake sold-out Pattern Fragments and Bottled Presence.
- [ ] Join the Cult (Sorry, Fan Club) — membership form, ranks and initiation ritual.
- [ ] Ugandalen Compatibility Quiz — determine whether the outfit would accept you.
- [ ] Emergency Protocol — printable instructions for lobby manifestations.
- [ ] Download Centre — wallpapers, badges and desktop companions.
- [ ] Webring — fictional affiliated sites such as `pattern-truth.net`.
- [ ] Expanded Guestbook — prewritten messages from suspicious witnesses.

## Tone rules

- Never reveal the person behind Ugandalen.
- Treat rumours as evidence and evidence as suspicious.
- Make the outfit feel like an artifact with its own agency.
- Keep the language funny, dramatic and completely overconfident.
- Preserve the chaotic Web 1.0 presentation.
